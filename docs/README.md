# Documentacao do Projeto - PI2 Squad E7

Nesta pasta ficam reunidos todos os documentos de especificacao, relatorios de entregas e diagramas do projeto integrador.

## Organizacao das Pastas do Projeto

* `src/`: Codigo-fonte da aplicacao em C (U1) e Haskell (U2), incluindo arquivos `.c` e cabecalhos `.h`.
* `bin/`: Diretorio de saida para os executaveis compilados.
* `docs/`: Documentos de arquitetura, requisitos (RF/RNF), modelagem de dados e regras de negocio.

## Comandos de Compilacao (Makefile)

* `make`: Compila o projeto gerando o binario em `bin/jogo`.
* `make run`: Compila e executa o jogo no terminal.
* `make clean`: Remove binarios e arquivos objeto temporarios.
