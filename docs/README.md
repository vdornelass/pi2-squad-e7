# 📚 Documentação do Projeto - PI2 Squad E7

Nesta pasta ficam reunidos todos os documentos de especificação, relatórios de entregas e diagramas do projeto integrador.

## 📂 Organização das Pastas do Projeto

* `src/`: Código-fonte da aplicação em C (U1) e Haskell (U2), incluindo arquivos `.c` e cabeçalhos `.h`.
* `bin/`: Diretório de saída para os executáveis compilados.
* `docs/`: Documentos de arquitetura, requisitos (RF/RNF), modelagem de dados e regras de negócio.

## 🛠️ Comandos de Compilação (Makefile)

* `make`: Compila o projeto gerando o binário em `bin/jogo`.
* `make run`: Compila e executa o jogo no terminal.
* `make clean`: Remove binários e arquivos objeto temporários.
