## Estrutura do Repositorio

```text
pi2-squad-e7/
├── bin/          # Executaveis compilados (ignorado no Git)
├── docs/         # Documentacoes tecnicas e especificacoes
├── src/          # Codigo-fonte em C (U1) e Haskell (U2)
├── .gitignore    # Configuracao de arquivos ignorados
└── README.md     # Apresentacao do projeto e da squad
```

## Como Compilar e Executar (C - U1)

```bash
# Compilar o codigo principal
gcc -Wall -Wextra src/main.c -o bin/jogo

# Executar
./bin/jogo
```
